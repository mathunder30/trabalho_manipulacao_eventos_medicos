# Sistema de Manipulação de Eventos Médicos

Este projeto é um sistema para gerenciar e visualizar informações médicas, como histórico do paciente, medicações, procedimentos realizados e observações médicas. Ele foi construído utilizando HTML, CSS e JavaScript, com foco na manipulação de dados de pacientes em ambiente web.

## Funcionalidades

- **Histórico Médico**: Exibe e manipula o histórico médico do paciente.
- **Informações Pessoais do Paciente**: Gerenciamento dos dados pessoais do paciente.
- **Medicação**: Controle e exibição das medicações do paciente.
- **Observações Médicas**: Registro de observações feitas durante o atendimento médico.
- **Procedimentos Realizados**: Armazenamento e visualização dos procedimentos realizados no paciente.
- **Visualização de Dados**: Página para visualizar o prontuário completo do paciente com todas as informações mencionadas acima.

## Estrutura do Projeto

- `historico_med.html`: Página para manipular o histórico médico do paciente.
- `informacao_pessoais_paciente.html`: Gerencia as informações pessoais do paciente.
- `medicacao.html`: Página que exibe e manipula informações de medicação.
- `obs_med.html`: Página para registrar observações médicas.
- `procedimento_realizados.html`: Página para manipulação dos procedimentos realizados.
- `pagina_visualizacao.html`: Interface para visualização de todas as informações do paciente.
- `*.css`: Arquivos de estilo responsáveis pelo design das páginas.
- `*.js`: Arquivos JavaScript que contêm a lógica para manipulação de dados nas respectivas páginas.

## Pré-requisitos

- Navegador Web moderno (como Google Chrome, Mozilla Firefox, etc.)

## Como executar

1. Clone este repositório para sua máquina local:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Abra o arquivo `index.html` no seu navegador para acessar a página principal do sistema.

3. A partir da página principal, navegue pelas diferentes seções, como histórico médico, medicações, observações médicas, e procedimentos realizados.

## Personalização

Se quiser personalizar o projeto, edite os arquivos `.css` para modificar o estilo das páginas ou ajuste os arquivos `.js` para alterar a lógica de manipulação dos dados.
